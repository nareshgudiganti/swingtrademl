# Audit of 2026-10-13 — findings and status

**What this is:** a read-only technical and trading-validation audit of TradeMind, followed by fixes.
Each problem has an ID (F-01, F-02 …) so it can be referred to in one word. This file is the one place
that lists them and says where each stands. Update the Status column when something changes.

**Bottom line:** nothing in the repo shows the model picks stocks better than random, and the go-live gate
does not require it. The fixes below make the measuring honest; they do not make the app profitable.

Test state when this was written: **1536 passed, 0 failed** (`develop`, with Docker Postgres up).

## Status key
**Fixed** = changed, tested, committed. **Open — you** = needs the owner's decision or action.
**Open — me** = can be done next without a decision. **Not verified** = suspected, not proven.

## F-07 detail: the 16 big one-day moves (local candles, 306 stocks, 2021-08 to 2026-09)

How they were sorted: **volume on the day against the previous 20-day average**. A big move on heavy volume is
usually real news. A big move on ordinary or thin volume that never reverses usually means the price basis
changed (a split, demerger or ex-date that was not adjusted) or the data is wrong. This is a signature, **not
proof**: nothing here was checked against exchange records.

| Looks like | Stock (day, move, volume vs normal) | In the 49 watchlist? |
|---|---|---|
| **Price basis probably changed** (thin volume, no rebound) | ALLCARGO (2025-11-12, −60%, 1.0×), TRIVENI (2026-07-22, −42%, 0.25×), SANOFI (2024-06-13, −28%, 0.7×), SCI (2023-03-31, +30%, 0.4×), BAJAJELEC (2023-09-14, +39%, 0.1×) | No |
| **Unclear — check** | VEDL (2026-04-30, −33%, 1.9×), NMDC (2022-10-27, +86%, 2.0×), SIEMENS (2025-04-07, −25%, 3.5×), IDEA (2021-09-16, +26%, no baseline) | No |
| **Probably a real move** (heavy volume) | ABFRL (2025-05-22, −56%, 6×), IEX (2025-07-24, −30%, 19×), OFSS (2024-01-18, +30%, 19×), RECLTD (2024-06-04, −25%, 5.6×), ADANIENT (2023-02-01/02, −28%/−27%, 3–8×), INDUSINDBK (2025-03-11, −27%, 14×) | ADANIENT and INDUSINDBK: yes |

What it means: the 49-stock tests (walk-forward, replay) are barely touched, because none of the "price basis"
cases are in the watchlist. A retrain on the wider 306-stock list would be touched, so settle these first.
Also: `upcoming_events` only holds future events (2026-09-21 to 2026-11-02), so the existing split-check could
never have judged past moves. The earlier "clean" result only covered events that table knew about.
