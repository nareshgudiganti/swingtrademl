# Audit of 2026-10-13 — findings and status

**What this is:** a read-only technical and trading-validation audit of TradeMind, followed by fixes.
Each problem has an ID (F-01, F-02 …) so it can be referred to in one word. This file is the one place
that lists them and says where each stands. Update the Status column when something changes.

**Bottom line:** nothing in the repo shows the model picks stocks better than random, and the go-live gate
does not require it. The fixes below make the measuring honest; they do not make the app profitable.

Test state when this was written: **1536 passed, 0 failed** (`develop`, with Docker Postgres up).

## Status key
**Fixed** = changed, tested, committed. **Open — you** = needs the owner's decision or action.
**Open — me** = can be done next without a decision. **Not verified** = suspected, not proven.

## Decisions waiting for the owner
1. **Gate numbers (F-01).** Recommended starting point: at least 15 sessions, at least 30 finished ideas, average result
   per idea above zero after costs, edge over "every stock" above zero. Numbers can change later.
2. **Retrain prod models (F-02)** — yes or no, and on which question.
3. **Rescore old ideas (F-03)** — recommended yes; needs a migration.
4. **`ingested_at` column (F-07)** — needs a migration.
5. **Merge `develop` to `main` (F-04)** — check `JWT_SECRET_KEY` on the server first.

## Known limits of this audit
- Prod was checked read-only through its API; the server, logs and prod secrets were not seen.
- The walk-forward, horizon grid and replays were read as published, not re-run.
- Local candles end 2026-09-08; prod's end 2026-10-12.
